Clessy is a hobby UCI chess engine written from scratch in C++.

It communicates exclusively through the UCI protocol, so using a GUI or TUI that supports it is recommended.

I suggest [Cute Chess](https://cutechess.com/) as a GUI, or you can try my TUI, [Cless](https://github.com/vinegm/cless).
